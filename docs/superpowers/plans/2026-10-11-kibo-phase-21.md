# Kibo · Phase 21 : Les agents parlent à l'agent de projet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** permettre à un run de ticket de **signaler** à l'agent de projet un ticket à créer, un blocage, un contexte ou une question (outil MCP `signal_project`), sans jamais rien créer lui-même : les signaux sont stockés par le démon, visibles dans le fil du run et dans une **boîte à signaux** du panneau de l'agent de projet ; `ticket` et `blocker` **réveillent** l'agent de projet au plus une fois par 10 minutes par projet, signaux regroupés ; l'agent lit les signaux à chaque tour et propose un **lot** qui les cite ; à la validation d'Adam, chaque signal devient « traité dans le lot n° k » ou « ignoré ».

**Architecture:** `schema` (signal, événements, `foldSignal`, outil et spec MCP, `signals`/`dismissSignal` dans les lots, moment `signal`, action `signal`, RPC et compteurs) → `core` (planificateur de réveil pur, message de réveil, section « Signaux à traiter », validation des références de signal, règlement `signalOutcomes`, consignes) → `daemon` (`signals/` : store sur `runs.db`, service d'enregistrement, planificateur avec minuteries injectées ; route MCP des runs de ticket étendue ; agent de projet : signaux dans le tour, `list_signals`, règlement à l'application ; trace : moment `signal`, service découpé) → `ui` (onglets du panneau, boîte, pastille chiffrée, provenance dans la carte de lot, ligne de réveil, `SignalMoment` dans le fil) → intégration, E2E, Penpot, jalon.

**Tech Stack:** TypeScript strict, Zod, Bun (`bun:sqlite`, seconde connexion sur `runs.db`), React 19 + shadcn/ui (`Tabs` déjà dans le SDK), fast-check, Playwright ; **aucune dépendance nouvelle**.

**Spec:** conception **§27.1 à §27.10** (autorité ; amende §23.12.2, §24.3, §24.4, §24.5, §24.7, §26.2, §26.3 et la spec agents §3) ; cadre validé par Adam le 2026-10-10 ; rapport du jalon précédent `docs/superpowers/rapports/2026-10-11-jalon-v0.20.md` (contraintes : budget 223,6 kB, fichiers à découper, ports) ; CLAUDE.md.
