# Kibo · Phase 28 : un dépôt sans données client Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** le dépôt GitHub est public ; il ne doit plus contenir aucune donnée d'un projet client (spec **§40**, demande d'Adam du 2026-10-18, choix « tout neutraliser », historique git laissé tel quel). Un **garde-fou** (test du dépôt) lit la liste des termes interdits hors dépôt (`~/.config/kibo/termes-interdits.txt`), échoue dès qu'un terme apparaît dans un fichier suivi ou dans un nom de fichier, et est sauté quand la liste est absente (CI). Il est **rouge au départ et vert au jalon**. Un **projet fictif de suivi, « Silo »** (clé `SILO`, location de box), défini dans `design/donnees-fictives.md`, remplace le projet client partout : tests, semis E2E, projet de démonstration, aide de la CLI, i18n, maquettes Penpot et leurs exports, spec, plans et rapports. Le script d'import et de rebase propre au client est **retiré du dépôt** (Adam en garde une copie hors dépôt). Les pages 35 et 36 du redesign sont **redessinées** avec les données fictives, en sombre et en clair ; `kibo.penpot.xz`, les PDF et `design/redesign/exports/` sont réexportés ; l'**acceptation au pixel près** (2 % de l'écran entier, aucun masque ajouté) est repassée contre les nouveaux exports.

**Architecture:** une seule source pour le vocabulaire fictif (« Contrats partagés », recopiée dans `design/donnees-fictives.md` par T2) ; un seul garde-fou (`scripts/forbidden-terms`, workspace sans dépendance, pur sauf `git ls-files` et la lecture des fichiers) ; un renommage **mécanique par zone**, à fichiers disjoints, pour que six devs travaillent en parallèle ; les maquettes redessinées **par les scripts existants** (données centralisées dans `02-data.js` et dans les tableaux de `50-proposition.js`, `55-phase-27.js`, `80-choix.js`), jamais à la main ; le pixel repassé une fois les exports et les semis alignés.

**Tech Stack:** Bun, TypeScript strict, Biome, Playwright 1.55 (`toHaveScreenshot`, `maxDiffPixelRatio 0.02`), Penpot auto-hébergé piloté en **Chromium headless** (Playwright, CDP) par le plugin MCP et `receiver.py` (port 8787), `pdftotext`/`pdfinfo` (poppler), `pypdf` dans un venv local (hors dépôt), `xz`.

**Spec:** `docs/superpowers/specs/2026-09-25-kibo-design.md` §40 (et les §23, §30, §35, §37, §39 qu'elle neutralise).

**Interdit absolu :** aucun terme de `~/.config/kibo/termes-interdits.txt` ne doit être écrit dans un fichier du dépôt, dans un message de commit, dans un nom de branche ni dans un rapport. Pour en parler on écrit « le nom du client », « la clé du client », « le terme métier du client », ou « terme n » (numéro de ligne dans la liste). La correspondance entre le projet client et Silo n'est écrite **nulle part** dans le dépôt.

## Global Constraints

- **Aucun terme interdit, nulle part** : ni dans un fichier, ni dans un nom de fichier, ni dans un commit, ni dans une branche, ni dans un rapport, ni dans une remarque de review. Chaque dev vérifie sa zone avant chaque commit : `FORBIDDEN_TERMS_SCOPE=<zone> bun test scripts/forbidden-terms` (T1). Le garde-fou complet est rouge jusqu'au jalon : c'est voulu.
- **Aucune correspondance écrite** : on ne dit jamais que Silo « remplace » tel client ; les docs historiques disent « le projet client ».
- **Machine d'Adam** : aucune tâche ne lit ni n'écrit `~/.kibo`, le démon réel, `~/Documents`, ni le registre `full-delivery` ; les tests n'écrivent que dans un `mkdtemp`.
- **Renommage mécanique, comportement inchangé** : aucune logique ne change ; un test qui change de résultat révèle une dépendance cachée au nom du client (à corriger, pas à contourner). Les longueurs de texte restent proches des originaux (voir le dictionnaire) pour ne pas déplacer la mise en page des maquettes.
- **Un seul langage de dessin** : les maquettes sont redessinées par les scripts (`02-data.js` et les tableaux inlinés), jamais retouchées à la main ; Penpot uniquement en Chromium headless (jamais le Chrome d'Adam), sous `_outils/.penpot.lock`, `receiver.py` propre à la tâche sur 8787 une fois le port vérifié libre.
- **Pixel** : écran entier, ≤ 2 %, **aucun masque ajouté** (`pixel-masks.ts` ne gagne aucune entrée ; seuls ses libellés changent) ; semis E2E = nouvelles maquettes au texte près.
- **Budget UI** : exigence ≤ 224 000 octets gzip ; le renommage n'ajoute rien à l'entrée ; `bun run budget` à T6.
- **Code** : TypeScript strict, aucun commentaire, pas de `any`, exports nommés, kebab-case ; `scripts/forbidden-terms` sans dépendance runtime.
- **Historique git intact** : pas de réécriture, pas de force-push (décision d'Adam).
- Git : branche `feat/p28-t<n>` depuis `phase/28`, worktree `.claude/worktrees/p28-t<n>` ; commits d'une ligne en français, préfixe conventionnel, **< 50 caractères** (`wc -m`), fichiers stagés explicitement, aucune mention d'IA. `bun run check && bun run typecheck && bun test <zone>` verts avant chaque commit final, plus le garde-fou borné à la zone ; tests d'intégration sous `_outils/.integ.lock`.
