**Goal:** importer dans Kibo toutes les ressources du projet Emis (72 PR du plan, 15 chapitres, 16 arbitrages, TODO, fichiers de pilotage et briefs) et rendre Emis **maintenable uniquement avec Kibo** : worktrees frères du dépôt créés depuis `origin/dev` par `pnpm worktree`, agents en mode `auto` lancés par la file de Kibo, « Terminé » quand la PR est fusionnée sur `dev`, plan et notes dans Kibo seul.

**Architecture:** cinq fonctions génériques de Kibo (étiquettes ; références `git_branch` et `import_ref` ; réglages de worktree locaux par projet avec adoption et commande de préparation ; mode `auto` et règles `allow` par profil, un run par ticket ; `base`/`head` des PR et règle « Terminé » conditionnée à la branche d'intégration avec cascade des PR empilées), toutes posées **d'abord dans le schéma** (T1, courte), puis implémentées en parallèle dans leurs paquets (T2 à T5, fichiers disjoints) ; un **script d'import** `scripts/import-emis` (T6) qui ne dépend que de `@kibo/schema`, lit les fichiers d'Emis par `node:vm` et `node:fs`, calcule un état désiré pur, le réconcilie avec `getProject` par `import_ref` et n'envoie que des commandes publiques (`createTicket`, `updateTicket`, `setStatus`, `moveTicket`, `addLink`, `upsertExternalRef`, `addPage`, `addInstance`, `config`, `setNotesDir`), testé sur un **dossier Emis fictif** et un démon éphémère ; puis l'import réel précédé d'une sauvegarde, un ticket pilote, la bascule (T7) et le jalon `0.17.0-alpha.1` (T8).

**Tech Stack:** Bun 1.4.2, TypeScript 5.9 strict, Zod 3.25.76, Loro, React 19, shadcn/ui, Tailwind 4, fast-check, happy-dom + Testing Library, Playwright, `node:vm`. **Aucune dépendance nouvelle.**

## Décisions d'exécution

Les décisions de comportement sont dans la spec (§23, agents §17, code et onglets §15, composants §21) ; le plan ne les répète pas.

1. **Schéma d'abord, en une tâche courte** (T1) : tous les champs nouveaux et leurs validateurs purs (`LabelName`, `normalizeLabels`, `GitBranchName`, `ImportSource`, `AllowRule`, `WorktreeSettings`, `resolveWorktreePath`, `integrationBranch`) vivent dans `@kibo/schema` avec leurs tests ; T2 à T6 ne touchent plus `packages/schema` (sauf `index.ts` : non, T1 exporte tout). Les validateurs de chemin et de règle sont dans le schéma parce que le démon (refus à l'exécution) et l'interface (refus avant envoi) les partagent.
2. **Étiquettes : liste remplacée, jamais fusionnée** : `updateTicket { labels }` écrit la liste entière normalisée (`normalizeLabels` : rognage, dédoublonnage, tri) ; l'interface envoie `[...t.labels, nouvelle]` ou la liste sans l'élément retiré. Pas de commande `addLabel`.
3. **`import_ref` plutôt que `mcp_item`** : variante dédiée (§23.3), masquée des pastilles (`refChip` rend `null`), visible en infobulle du titre de la fiche (`title` de l'élément).
4. **Réglages de worktree locaux** : `ProjectPatch.worktree` est retiré du patch avant `setProjectMeta` et `updateRegisteredProject` (`localFields`/`docFields` dans `projects/meta.ts`) et écrit dans `ProjectSettings` (clé `worktree`, JSON) ; `withLocalFolder` devient `withLocalSettings(meta, settings, shared)` et pose `folder` **et** `worktree` ; `ProjectMeta.worktree` est `null` dans les docs (jamais écrit). `ticketContext().project.meta.worktree` est donc rempli côté démon : `run-launch.ts` passe `worktree: ctx.project.meta.worktree` et `branchRef` (la `git_branch` du ticket) à `prepareWorkspace`.

import { KiboError } from "./errors";

export const LABEL_MAX = 20;
export const LabelName = z.string().regex(/^[a-z0-9][a-z0-9:_./-]{0,39}$/);
export const Labels = z.array(LabelName).max(LABEL_MAX);
export type Labels = z.infer<typeof Labels>;

export function normalizeLabels(labels: readonly string[]): string[] {
  const seen = new Set<string>();
  for (const raw of labels) {
    const label = raw.trim();
    if (!LabelName.safeParse(label).success) throw new KiboError("INVALID_INPUT", `invalid label ${JSON.stringify(raw)}`);
    seen.add(label);
  }
  if (seen.size > LABEL_MAX) throw new KiboError("INVALID_INPUT", `at most ${LABEL_MAX} labels`);
  return [...seen].sort();
}

export function labelPrefix(label: string): string | null {
  const at = label.indexOf(":");
  return at > 0 ? label.slice(0, at) : null;
}

export function groupLabels(labels: readonly string[]): { prefix: string | null; labels: string[] }[] {
  const sorted = normalizeLabels(labels);
  const free = sorted.filter((l) => labelPrefix(l) === null);
  const prefixes = [...new Set(sorted.map(labelPrefix).filter((p): p is string => p !== null))].sort();
  const groups = prefixes.map((prefix) => ({ prefix, labels: sorted.filter((l) => labelPrefix(l) === prefix) }));
  return free.length > 0 ? [{ prefix: null, labels: free }, ...groups] : groups;
}

async function ensureBranch(root: string, branch: string, base: string, git: GitRunner): Promise<void> {
  const known = await git(["rev-parse", "--verify", "--quiet", `refs/heads/${branch}`], root);
  if (known.code === 0) return;
  const { remote, branch: remoteBranch } = splitRemote(base);
  if (remote !== null) {
    const remotes = await git(["remote"], root);
    if (!remotes.stdout.split("\n").includes(remote)) throw gitFailed(`remote ${remote} not found`);
    const fetched = await git(["fetch", "--quiet", remote, remoteBranch], root);
    if (fetched.code !== 0) throw gitFailed(`git fetch ${remote} ${remoteBranch} failed: ${fetched.stderr.trim()}`);
  }
  const created = await git(["branch", "--no-track", branch, base === "main" && remote === null ? await mainOrHead(root, git) : base], root);
  if (created.code !== 0) throw gitFailed(`git branch ${branch} failed: ${created.stderr.trim()}`);
}

async function mainOrHead(root: string, git: GitRunner): Promise<string> {
  const main = await git(["rev-parse", "--verify", "--quiet", "refs/heads/main"], root);
  return main.code === 0 ? "main" : "HEAD";
}

async function excludeKiboFolder(root: string, git: GitRunner): Promise<void> {
  const res = await git(["rev-parse", "--git-path", "info/exclude"], root);
  if (res.code !== 0) throw gitFailed(`cannot locate info/exclude: ${res.stderr.trim()}`);
  const file = join(root, res.stdout.trim());
  const current = existsSync(file) ? Bun.file(file).text() : Promise.resolve("");
  const text = await current;
  if (text.split("\n").includes(".kibo/")) return;
  mkdirSync(dirname(file), { recursive: true });
  appendFileSync(file, `${text.length > 0 && !text.endsWith("\n") ? "\n" : ""}.kibo/\n`);
}

async function runSetup(input: WorktreeInput, branch: string, path: string): Promise<void> {
  const setup = input.settings.setup;
  if (setup === null) {
    const added = await input.git(["worktree", "add", path, branch], input.root);
    if (added.code !== 0) throw gitFailed(`git worktree add failed: ${added.stderr.trim()}`);
    return;
  }
  const command = renderTemplate(setup, { branch, slug: branchSlug(branch), key: input.ticketKey.toLowerCase(), path });
  const env = { ...Object.fromEntries(Object.entries(process.env).filter((e): e is [string, string] => e[1] !== undefined)), KIBO_BRANCH: branch, KIBO_WORKTREE: path, KIBO_TICKET: input.ticketKey };
  const result = await input.shell(command, input.root, env, SETUP_TIMEOUT_MS);
  mkdirSync(input.runDir, { recursive: true, mode: 0o700 });
  writeFileSync(join(input.runDir, "setup.log"), `$ ${command}\n${result.output}`, { mode: 0o600 });
  if (result.timedOut) throw new KiboError("TIMEOUT", `setup command exceeded ${SETUP_TIMEOUT_MS / 1000}s`);
  if (result.code !== 0) throw failed(`setup command exited with ${result.code}:\n${tail(result.output)}`);
  if (!existsSync(path) || !(await isWorktreeAt(path, input.git))) throw failed(`setup did not create a worktree at ${path}:\n${tail(result.output)}`);
}

export async function prepareWorktree(input: WorktreeInput): Promise<PreparedWorkspace> {
  const branch = worktreeBranch(input.ticketKey, input.branchRef);
  const vars = { branch, slug: branchSlug(branch), key: input.ticketKey.toLowerCase() };
  let path: string;
  try {
    path = resolveWorktreePath(input.root, input.settings.pathTemplate, vars);
  } catch (e) {
    throw failed(e instanceof KiboError ? e.detail : String(e));
  }
  if (input.settings.pathTemplate.startsWith(".kibo/")) await excludeKiboFolder(input.root, input.git);
  if (existsSync(path)) {
    if (!(await isWorktreeAt(path, input.git))) throw gitFailed(`${path} exists but is not a worktree`);
    return { cwd: path, label: `worktree:${branch}` };
  }
  await ensureBranch(input.root, branch, worktreeBase(input.settings, input.branchRef), input.git);
  await runSetup(input, branch, path);
  const actual = await branchAt(path, input.git);
  if (actual !== branch) throw failed(`worktree is on ${actual}, expected ${branch}`);
  return { cwd: path, label: `worktree:${branch}` };
}

import type { ExternalRef, GithubPrRef } from "@kibo/schema";

export type PrTicket = { id: string; refs: readonly ExternalRef[] };

const mergedPr = (refs: readonly ExternalRef[]): GithubPrRef | null =>
  refs.find((r): r is GithubPrRef => r.kind === "github_pr" && r.state === "merged") ?? null;

export function mergeCascade(tickets: readonly PrTicket[], mergedHead: string): string[] {
  const out: string[] = [];
  const seen = new Set<string>([mergedHead]);
  const queue = [mergedHead];
  while (queue.length > 0) {
    const head = queue.shift() as string;
    for (const t of tickets) {
      const pr = mergedPr(t.refs);
      if (pr === null || pr.base !== head || pr.head === null || seen.has(pr.head)) continue;
      seen.add(pr.head);
      out.push(t.id);
      queue.push(pr.head);
    }
  }
  return out;
}
