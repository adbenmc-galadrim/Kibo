# Kibo · Phase 14 : installation et finition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** livrer la section « Phase 14 » de la feuille de route et les demandes d'Adam du 2026-10-04 : (1) une **installation la plus simple possible** (`.dmg` arm64 et Intel signé ad hoc, `.deb`/`.rpm`/AppImage avec `.desktop` et icônes, `SHA256SUMS` et `install.sh`, page d'installation qui explique la confiance macOS) ; (2) un **premier lancement complété** (vérifications `claude`, `git`, `gh` avec aide et « Réessayer ») qui propose le didacticiel ; (3) les **finitions** : « Lancer au démarrage », « Quoi de neuf » après mise à jour, « Signaler un problème » sans secret, **sauvegardes automatiques** de `~/.kibo`, aide des raccourcis `⌘/`, fenêtre « À propos » ; (4) le **didacticiel par la pratique** dans un projet de démonstration supprimable en un clic, avec un **agent de démonstration qui ne consomme aucun token**. Aucune signature ni notarisation Apple (décision d'Adam) ; aucun secret nouveau ; budget initial ≤ 230 kB jamais relevé.

**Architecture:** la coque reste « Rust minimal » : un plugin de plus (`autostart`), trois permissions dans la capacité accordée à l'origine du démon, un événement `kibo:about` ; tout le reste vit dans le démon (TypeScript testé) et dans des écrans **chargés à la demande**. Le démon gagne quatre petits services sans I/O cachée : `app-info` (version injectée à la compilation), `diagnostics` (rapport rédigé, tampon de journal en mémoire), `backups` (`VACUUM INTO` + copie, horloge injectée), `demo` (projet et agent de démonstration, état du didacticiel dans `local_state`). L'agent de démonstration **est** le faux `claude` des tests, compilé en troisième `externalBin` et choisi par le lanceur pour le seul profil système `demo` : la file, les hooks, la question, `--resume` sont ceux des vrais runs. La détection des étapes du didacticiel est déterministe (événements du doc et des runs), jamais textuelle. La publication ajoute Intel, `SHA256SUMS`, `install.sh` et le `CHANGELOG.md` comme source unique de « Quoi de neuf » et du corps des releases.

**Tech Stack:** Bun 1.4.2, TypeScript 5.9 strict, Zod 3.25.76, React 19, shadcn/ui, happy-dom + Testing Library, Playwright ; Tauri 2.12.0 (`@tauri-apps/cli` 2.11.5) ; **nouvelles dépendances** : `tauri-plugin-autostart` 2.7.0 (Rust) et `@tauri-apps/plugin-autostart` 2.7.0 (JS, `packages/ui`), figées par `Cargo.lock` et `bun.lock`, sans `postinstall`, justifiées par « Lancer au démarrage » (feuille de route). `bun:sqlite` 3.51.0 (`VACUUM INTO` vérifié par le lead).

**Spec:** `docs/superpowers/specs/2026-09-25-kibo-design.md` **§20** (écrite pour ce plan : 20.1 distribution, 20.2 premier lancement, 20.3 À propos et rapport, 20.4 Quoi de neuf, 20.5 sauvegardes, 20.6 raccourcis, 20.7 ports/écrans/budget, 20.8 didacticiel) ; `docs/superpowers/specs/2026-09-26-kibo-agents.md` **§15** (agent de démonstration) ; `docs/superpowers/specs/2026-09-27-kibo-mises-a-jour.md` **§7** (amendements : ad hoc, Intel, `SHA256SUMS`, sauvegarde avant mise à jour) ; spec IA §4.3, §5.1, I12, I18, I29, I32, I39 (écran 19, profils système, faux `claude`). Sources : feuille de route « Phase 14 » ; demandes d'Adam du 2026-10-04 ; `docs/superpowers/rapports/2026-10-04-jalon-v1.4.md` ; `docs/superpowers/plans/2026-10-04-kibo-phase-13.md` (format).

## Review Focus

1. **Sauvegarde pendant une écriture** (T4) : une sauvegarde lancée alors que le démon écrit dans `kibo.db` produit un fichier qui s'ouvre et passe `PRAGMA integrity_check` ; la WAL n'est pas copiée telle quelle (`VACUUM INTO` la fusionne) ; test `backup-fs.test.ts` qui écrit dans la base pendant `writeBackup` (transaction ouverte avant, validée après) et rouvre la copie.
2. **Dossier de sauvegarde pointé vers un endroit interdit** (T4) : `setBackupSettings { dir: "<KIBO_HOME>" }` ou un dossier qui contient `<KIBO_HOME>` est refusé (`INVALID_INPUT`, une sauvegarde ne doit jamais se copier elle-même), un lien symbolique est résolu par `realpath` avant le contrôle, un chemin relatif ou inexistant est refusé ; test `service.test.ts`.
3. **Agent de démonstration hors de la démo** (T6) : `assignAgent` avec le profil `demo` sur un ticket d'un projet non marqué `demo` ⇒ `INVALID_INPUT` « the demo agent only works in the demo project » ; le dialogue « Assigner » ne le liste pas ; un run `demo` qui tente un `Write` hors de son espace isolé est refusé par le hook et le refus apparaît dans le journal du run ; tests `orchestrator.test.ts`, `demo-agent.int.test.ts`, `assign-dialog.test.tsx`.
4. **Rapport avec un chemin personnel et un jeton dans le journal** (T3) : une ligne de journal `"[kibo-daemon] pair failed token=abc123 at /Users/adam/.kibo/x"` ressort `"[kibo-daemon] pair failed token=[redacted] at ~/.kibo/x"` ; le rapport ne contient ni `token`, ni `daemon.json`, ni `Set-Cookie`, ni `?` d'URL ; tests `redact-paths.test.ts` (fast-check : le dossier personnel ne survit jamais, quelle que soit la ligne) et `daemon.test.ts` (le JSON de `getDiagnostics` ne contient pas le jeton réel, provoqué dans le journal).
5. **Somme de contrôle altérée** (T13) : `install.sh` face à un `SHA256SUMS` dont la ligne du paquet ne correspond pas s'arrête avant toute installation, code 1, message « La somme de contrôle ne correspond pas », aucun fichier posé dans `~/.local/bin` ni `~/.local/share` ; test `install.test.ts`.

## Décisions d'exécution

Les décisions de comportement sont dans les specs (conception §20, agents §15, mises à jour §7) ; le plan ne les répète pas.

1. **Version du démon** : `build-sidecar.ts` passe `define: { "process.env.KIBO_VERSION": JSON.stringify(readAppVersion(tauriConf)) }` à `Bun.build` ; `appVersion()` lit `process.env.KIBO_VERSION` sinon `tauri.conf.json` par `readAppVersion` (devkit) : une seule source (`version.ts`). Aucune lecture de `package.json`.
2. **Journal mémoire** : `createLogBuffer(500)` enveloppe `console.error` et `console.warn` **avant** `installConsoleRedaction` dans `main.ts`, de sorte que la rédaction enveloppe le tampon : le tampon ne reçoit que du texte rédigé. Il ne change pas la sortie stderr.
3. **RPC nouvelles = extensions** (`RpcExtension`), une par service : `appRpc` (T3 : `getAppInfo` ouverte, `getDiagnostics` locale), `backupsRpc` (T4, toutes locales), `tutorialRpc` (T5, toutes locales). Les méthodes sont déclarées dans `packages/schema/src/phase14-rpc.ts` (`PHASE14_RPC`, `Phase14RpcResult`), fusionnées dans `RpcRequest`/`RpcResult` comme `SYNC_RPC_REQUESTS`.
4. **Événements** : `Phase7Event` gagne `backups.changed` et `tutorial.changed` (l'union s'appelle ainsi pour l'histoire ; aucun renommage).
5. **Pas de restauration dans l'application** : documentée (spec §20.5) ; une « Suite ».
6. **Didacticiel : état dans le démon** (`local_state` `setting:tutorial`), détection par **ré-évaluation** à chaque `ChangeMessage` du projet de démonstration et à chaque `run.changed` d'un run de ce projet (`evaluateTutorial(state, snapshot, runs)` pure, testée sur des instantanés), puis `tutorial.changed` si l'état change. L'ouverture de la page Graphe est le seul signal envoyé par l'interface (`markTutorialSeen { view: "graph" }`), parce que « voir le graphe » n'est pas une donnée.

Scénarios et fixtures : constantes TypeScript écrites dans `<KIBO_HOME>/demo-agent/` à la première assignation.
9. **Un seul groupe « Aide »** dans le menu de l'avatar, posé par T8 avec ses cinq entrées et les cinq clés `DialogsState` (`about`, `whatsNew`, `shortcutsHelp`, `report`, `tutorial`) ; T10 et T12 n'ajoutent que leurs composants paresseux dans `lazy-dialogs.ts` et `ShellDialogs.tsx` (lignes ajoutées, rebase trivial).
10. **`CHANGELOG.md`** : source unique de « Quoi de neuf » (import `?raw` dans un morceau paresseux) et du corps de la release ; `changelogSection(markdown, version)` dans `packages/schema/src/changelog.ts` (pur, sans dépendance) pour le devkit, la CI et l'interface.
11. **Suppression en un clic** : `DeleteProjectDialog` reçoit `project.demo` et, s'il est vrai, remplace la saisie du nom par un bouton unique ; `deleteProject` est inchangée.
12. **E2E du didacticiel** : le démon E2E tourne avec `--claude-bin fake-claude.ts` ; le profil `demo` utilise `demoAgentBin()` = ce même script en développement, avec ses propres scénarios : aucun drapeau nouveau.

`packages/schema/src/changelog.ts` :
```ts
const HEADING = /^## (\d+\.\d+\.\d+)(?: — .*)?$/;

type Section = { version: string; body: string };

function sections(markdown: string): Section[] {
  const out: Section[] = [];
  let current: Section | null = null;
  for (const line of markdown.split("\n")) {
    if (line.startsWith("## ")) {
      const version = HEADING.exec(line)?.[1];
      current = version ? { version, body: "" } : null;
      if (current) out.push(current);
      continue;
    }
    if (current) current.body += `${line}\n`;
  }
  return out.map((s) => ({ ...s, body: s.body.trim() }));
}

export function changelogSection(markdown: string, version: string): string | null {
  return sections(markdown).find((s) => s.version === version)?.body ?? null;
}

export const changelogVersions = (markdown: string): string[] => sections(markdown).map((s) => s.version);
```

```ts
import { AppArch, type AppInfo, AppPlatform, KiboError } from "@kibo/schema";

export function abbreviateHomePath(path: string, userHome: string): string {
  if (path === userHome) return "~";
  return path.startsWith(`${userHome}/`) ? `~${path.slice(userHome.length)}` : path;
}

type Deps = { version: string; home: string; userHome: string; pid: number; startedAt: number; now(): number; platform: string; arch: string };

export function createAppInfo(deps: Deps): () => AppInfo {
  const platform = AppPlatform.safeParse(deps.platform);
  if (!platform.success) throw new KiboError("INTERNAL", `unsupported platform ${deps.platform}`);
  const arch = AppArch.safeParse(deps.arch);
  if (!arch.success) throw new KiboError("INTERNAL", `unsupported architecture ${deps.arch}`);
  const home = abbreviateHomePath(deps.home, deps.userHome);
  return () => ({
    version: deps.version,
    platform: platform.data,
    arch: arch.data,
    home,
    daemonPid: deps.pid,
    uptimeMs: Math.max(0, deps.now() - deps.startedAt),
  });
}
```

```ts
export type LogBuffer = { install(target: Pick<Console, "error" | "warn">): () => void; tail(n: number): string[] };

const text = (args: unknown[]): string =>
  args.map((a) => (a instanceof Error ? `${a.name}: ${a.message}` : typeof a === "string" ? a : JSON.stringify(a))).join(" ");

export function createLogBuffer(capacity = 500): LogBuffer {
  const lines: string[] = [];
  const push = (level: "error" | "warn", args: unknown[]) => {
    lines.push(`${level} ${text(args)}`);
    if (lines.length > capacity) lines.splice(0, lines.length - capacity);
  };
  return {
    install(target) {
      const { error, warn } = target;
      target.error = (...args: unknown[]) => {
        push("error", args);
        error.apply(target, args);
      };
      target.warn = (...args: unknown[]) => {
        push("warn", args);
        warn.apply(target, args);
      };
      return () => {
        target.error = error;
        target.warn = warn;
      };
    },
    tail: (n) => lines.slice(-n),
  };
}
```

```ts
import { existsSync } from "node:fs";
import { chmod, cp, mkdir, readdir, readFile, rename, rm, stat, writeFile } from "node:fs/promises";
import { join } from "node:path";
import { BackupId, type BackupInfo, type BackupReason, KiboError } from "@kibo/schema";

export const BACKUP_COPIED = ["components", "notes"] as const;
export const BACKUP_EXCLUDED = ["token", "daemon.json", "mcp", "remote", "tmp", "runs", "bin", "files", "backups", "demo-agent"] as const;
export type BackupDatabase = { file: string; vacuumInto(path: string): void };
export type WriteBackupInput = { home: string; dest: string; id: string; reason: BackupReason; appVersion: string; now: number; databases: BackupDatabase[] };

type Manifest = BackupInfo & { entries: string[] };

function assertId(id: string): void {
  if (!BackupId.safeParse(id).success) throw new KiboError("INVALID_INPUT", `${id} is not a backup id`);
}

async function sizeOf(path: string): Promise<number> {
  const s = await stat(path);
  if (!s.isDirectory()) return s.size;
  const children = await readdir(path);
  let total = 0;
  for (const child of children) total += await sizeOf(join(path, child));
  return total;
}

export async function writeBackup(input: WriteBackupInput): Promise<BackupInfo> {
  assertId(input.id);
  const final = join(input.dest, input.id);
  const staging = `${final}.partial`;
  await rm(staging, { recursive: true, force: true });
  await mkdir(staging, { recursive: true, mode: 0o700 });
  await chmod(staging, 0o700);
  const entries: string[] = [];
  for (const db of input.databases) {
    const target = join(staging, db.file);
    db.vacuumInto(target);
    await chmod(target, 0o600);
    entries.push(db.file);
  }
  for (const name of BACKUP_COPIED) {
    const source = join(input.home, name);
    if (!existsSync(source)) continue;
    await cp(source, join(staging, name), { recursive: true, dereference: false, errorOnExist: false, force: true });
    entries.push(name);
  }
  const bytes = await sizeOf(staging);
  const manifest: Manifest = { id: input.id, createdAt: input.now, reason: input.reason, bytes, appVersion: input.appVersion, entries };
  await writeFile(join(staging, "manifest.json"), JSON.stringify(manifest, null, 2), { mode: 0o600 });
  await rename(staging, final);
  const { entries: _entries, ...info } = manifest;
  return info;
}

export async function readBackups(dest: string): Promise<BackupInfo[]> {
  if (!existsSync(dest)) return [];
  const out: BackupInfo[] = [];
  for (const name of await readdir(dest)) {
    if (!BackupId.safeParse(name).success) continue;
    try {
      const parsed = JSON.parse(await readFile(join(dest, name, "manifest.json"), "utf8"));
      const info = BackupInfo.safeParse(parsed);
      if (info.success && info.data.id === name) out.push(info.data);
    } catch (e) {
      console.warn(`[kibo-daemon] backup ${name} has no readable manifest`, e);
    }
  }
  return out.sort((a, b) => a.createdAt - b.createdAt);
}

export async function removeBackupDir(dest: string, id: string): Promise<void> {
  assertId(id);
  await rm(join(dest, id), { recursive: true, force: true });
}
```

```ts
import { type TutorialState, type TutorialStep, TUTORIAL_STEPS } from "@kibo/schema";
import type { Instance, Link, RunView, TicketView } from "@kibo/schema";

export type TutorialSnapshot = {
  tickets: TicketView[];
  links: Link[];
  instances: Instance[];
  noteHash: string | null;
  runs: RunView[];
  aiComponentIds: string[];
};

const linkKey = (l: Link) => `${l.from}>${l.to}:${l.type}`;

const checks: Record<TutorialStep, (s: TutorialState, snap: TutorialSnapshot) => boolean> = {
  kanban: (s, snap) =>
    snap.tickets.some((t) => !s.seed?.ticketIds.includes(t.id) && t.status !== "todo" && t.status !== "backlog"),
  links: (s, snap) => s.seenViews.includes("graph") && snap.links.some((l) => !s.seed?.linkKeys.includes(linkKey(l))),
  note: (s, snap) => snap.noteHash !== null && snap.noteHash !== s.seed?.noteHash,
  dashboard: (s, snap) =>
    snap.instances.some((i) => {
      const was = s.seed?.layouts[i.id];
      return was !== undefined && (was.x !== i.layout.x || was.y !== i.layout.y || was.w !== i.layout.w || was.h !== i.layout.h);
    }),
  agent: (s, snap) => snap.runs.some((r) => r.profileId === "demo" && r.projectId === s.projectId && r.state === "done"),
  component: (_s, snap) => snap.instances.some((i) => snap.aiComponentIds.includes(i.component.split("@")[0] ?? "")),
};

export function evaluateTutorial(state: TutorialState, snap: TutorialSnapshot): TutorialState {
  if (state.status !== "active" || state.seed === null) return state;
  const completed = TUTORIAL_STEPS.filter((step) => state.completed.includes(step) || checks[step](state, snap));
  if (completed.length === state.completed.length) return state;
  const status = completed.length === TUTORIAL_STEPS.length ? "done" : "active";
  return { ...state, completed, status };
}
```

```ts
export type AutostartPort = { isEnabled(): Promise<boolean>; enable(): Promise<void>; disable(): Promise<void> };
type Plugin = Pick<typeof import("@tauri-apps/plugin-autostart"), "isEnabled" | "enable" | "disable">;
const loadPlugin = (): Promise<Plugin> => import("@tauri-apps/plugin-autostart");

export function createTauriAutostart(load: () => Promise<Plugin> = loadPlugin): AutostartPort {

}
```

```ts
const sum = (bytes: Uint8Array) => new Bun.CryptoHasher("sha256").update(bytes).digest("hex");

function serve(tamper = false) {
  const name = "Kibo_1.5.0_amd64.AppImage";
  const sums = `${tamper ? "0".repeat(64) : sum(appimage)}  ${name}\n${"1".repeat(64)}  Kibo_1.5.0_amd64.deb\n`;
  return Bun.serve({ port: 0, fetch(req) {
    const path = new URL(req.url).pathname;
    if (path.endsWith("/SHA256SUMS")) return new Response(sums);
    if (path.endsWith(`/${name}`)) return new Response(appimage);
    return new Response("not found", { status: 404 });
  } });
}

async function run(server: ReturnType<typeof serve>, home: string) {
  const proc = Bun.spawn(["bash", SCRIPT], { env: { ...process.env, KIBO_INSTALL_BASE_URL: `http://127.0.0.1:${server.port}`, KIBO_INSTALL_HOME: home, KIBO_INSTALL_FORMAT: "appimage", KIBO_INSTALL_ARCH: "x86_64" }, stdout: "pipe", stderr: "pipe" });
  const [out, err] = await Promise.all([new Response(proc.stdout).text(), new Response(proc.stderr).text()]);
  return { code: await proc.exited, out, err };
}

test("installs the AppImage, a desktop file and an icon when the checksum matches", async () => {
  const server = serve();
  const home = mkdtempSync(join(tmpdir(), "kibo-install-"));
  const r = await run(server, home);
  server.stop();
  expect(r.code).toBe(0);
  const bin = join(home, ".local/bin/kibo");
  expect(statSync(bin).mode & 0o111).not.toBe(0);
  expect(readFileSync(join(home, ".local/share/applications/kibo.desktop"), "utf8")).toContain(`Exec=${bin}`);
  expect(existsSync(join(home, ".local/share/icons/hicolor/512x512/apps/kibo.png"))).toBe(true);
  expect(r.out).toContain("Kibo 1.5.0 installé");
});

test("refuses a tampered checksum and installs nothing", async () => {
  const server = serve(true);

  const r = await run(server, home);
  server.stop();
```

```bash
#!/usr/bin/env bash
set -euo pipefail

BASE_URL="${KIBO_INSTALL_BASE_URL:-https://github.com/adbenmc-galadrim/Kibo/releases/latest/download}"
HOME_DIR="${KIBO_INSTALL_HOME:-$HOME}"
ARCH="${KIBO_INSTALL_ARCH:-$(uname -m)}"

fail() { echo "kibo : $*" >&2; exit 1; }
need() { command -v "$1" >/dev/null 2>&1 || fail "la commande $1 est nécessaire"; }
fetch() { curl -fsSL "$BASE_URL/$1" -o "$2" || fail "téléchargement impossible : $1"; }
sha256() { if command -v sha256sum >/dev/null 2>&1; then sha256sum "$1" | cut -d' ' -f1; else shasum -a 256 "$1" | cut -d' ' -f1; fi; }

[ "$ARCH" = "x86_64" ] || fail "architecture $ARCH non prise en charge : Kibo est publié pour Linux x86_64 (et macOS en .dmg)"
need curl

detect_format() {
  if [ -n "${KIBO_INSTALL_FORMAT:-}" ]; then echo "$KIBO_INSTALL_FORMAT"; return; fi
  if command -v apt-get >/dev/null 2>&1 && command -v dpkg >/dev/null 2>&1; then echo deb; return; fi
  if command -v dnf >/dev/null 2>&1; then echo rpm; return; fi
  echo appimage
}
FORMAT="$(detect_format)"

WORK="$(mktemp -d)"
trap 'rm -rf "$WORK"' EXIT
fetch SHA256SUMS "$WORK/SHA256SUMS"

VERSION="${KIBO_INSTALL_VERSION:-$(sed -n 's/^[0-9a-f]\{64\}  Kibo_\([0-9][0-9.]*\)_amd64\.AppImage$/\1/p' "$WORK/SHA256SUMS" | head -n1)}"
[ -n "$VERSION" ] || fail "version introuvable dans SHA256SUMS"

case "$FORMAT" in
  deb) ASSET="Kibo_${VERSION}_amd64.deb" ;;
  rpm) ASSET="Kibo-${VERSION}-1.x86_64.rpm" ;;
  appimage) ASSET="Kibo_${VERSION}_amd64.AppImage" ;;
  *) fail "format $FORMAT inconnu (deb, rpm ou appimage)" ;;
esac

verify() {
  local expected actual
  expected="$(grep "  $2\$" "$WORK/SHA256SUMS" | cut -d' ' -f1 || true)"
  [ -n "$expected" ] || fail "aucune somme publiée pour $2"
  actual="$(sha256 "$1")"
  [ "$expected" = "$actual" ] || fail "La somme de contrôle ne correspond pas pour $2 : fichier refusé"
}

fetch "$ASSET" "$WORK/$ASSET"
verify "$WORK/$ASSET" "$ASSET"

case "$FORMAT" in
  deb) sudo apt-get install -y "$WORK/$ASSET" ;;
  rpm) sudo dnf install -y "$WORK/$ASSET" ;;
  appimage)
    fetch icon-512.png "$WORK/icon-512.png"
    verify "$WORK/icon-512.png" icon-512.png
    install -d -m 0755 "$HOME_DIR/.local/bin" "$HOME_DIR/.local/share/applications" "$HOME_DIR/.local/share/icons/hicolor/512x512/apps"
    install -m 0755 "$WORK/$ASSET" "$HOME_DIR/.local/bin/kibo"
    install -m 0644 "$WORK/icon-512.png" "$HOME_DIR/.local/share/icons/hicolor/512x512/apps/kibo.png"
    cat > "$HOME_DIR/.local/share/applications/kibo.desktop" <<DESKTOP
[Desktop Entry]
Type=Application
Name=Kibo
Comment=Centre de contrôle local pour tes projets de code
Exec=$HOME_DIR/.local/bin/kibo
Icon=kibo
Terminal=false
Categories=Development;ProjectManagement;
Keywords=kanban;tickets;agents;claude;
StartupWMClass=kibo
DESKTOP
    command -v update-desktop-database >/dev/null 2>&1 && update-desktop-database "$HOME_DIR/.local/share/applications" || true
    ;;
esac

echo "Kibo $VERSION installé ($FORMAT). Lance-le depuis ton menu d'applications ; les données vivent dans ~/.kibo."
```
