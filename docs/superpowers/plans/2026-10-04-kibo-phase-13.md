# Kibo · Phase 13 : composants plus riches Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** répondre à la demande d'Adam du 2026-10-04 (les composants sont le centre de Kibo : 3D avec three.js, contenus Blender en glTF/GLB, jeux, et plus tard Figma) par huit livrables : (1) des **capacités** déclarées dans le manifeste (`webgl`, `audio`, `fullscreen`, `gamepad`, `assets`), montrées et acceptées à l'installation, appliquées par la CSP de chaque composant, l'attribut `allow` de son iframe, le démon et le SDK ; (2) un **kit 3D** `@kibo/sdk/three` ; (3) des **fichiers de projet hors CRDT** (GLB, images, sons) stockés, bornés, reconnus par leur signature et servis par jeton ; (4) un **kit jeu** `@kibo/sdk/game` avec le **mode plein écran de Kibo** ; (5) une **sélection partagée** entre les composants d'une page ; (6) des **réglages** générés plus riches (libellés, bornes, fichier du projet) ; (7) des **gabarits** (3D, jeu, graphique, tableau) dans la CLI et la création par l'IA, qui connaît les capacités ; (8) deux intégrés qui prouvent le tout : **Visionneuse 3D** et **Serpent**. Aucun token consommé par les tests ; aucune capacité réseau nouvelle (en attente d'Adam) ; budget initial ≤ 230 kB jamais relevé.

**Architecture:** les capacités sont des **permissions** (`cap:<nom>` dans `permissionList`, `GrantedPermissions.capabilities`) : tout ce qui existe pour les permissions (écran 30, `used ⊆ declared`, inférence statique, `declareMissing` de l'IA, journal des refus) les porte sans mécanisme nouveau. L'application est honnête : barrière du démon pour `assets`, barrière de la CSP pour `audio` et de la Permissions Policy pour `gamepad`, barrière de l'hôte pour `fullscreen`, validation pour `webgl` ; le runtime du bac à sable ajoute une défense en profondeur. Les fichiers de projet suivent le modèle des notes (dossier local par appareil, confinement `realpath`, signatures) avec un envoi par morceaux sous la limite de 3 Mio et un service par jeton éphémère sur le port bac à sable. Le mode plein écran et la sélection vivent dans l'hôte, en mémoire, et atteignent le composant par le protocole `postMessage` (sandbox) ou le contexte du SDK (intégrés). Les kits 3D et jeu isolent leur logique en fonctions pures testées sans GPU ; `three` est embarqué par chaque composant qui l'importe et interdit dans l'entrée de l'interface.

**Tech Stack:** Bun 1.4.2, TypeScript 5.9 strict, Zod 3.25.76, React 19, shadcn/ui, **three 0.186.1** et **@types/three 0.186.0** (nouvelles, figées par `bun.lock`, sans `postinstall`, justifiées par la demande d'Adam), happy-dom + Testing Library, fast-check 4.3.0, Playwright (Chromium, WebGL logiciel), Bun.serve.

**Spec:** `docs/superpowers/specs/2026-09-26-kibo-composants.md` **§19** (écrit pour ce plan, points 1 à 12) ; `docs/superpowers/specs/2026-09-25-kibo-design.md` **§19** (capacités, fichiers hors CRDT, plein écran, sélection, ports 4390–4460) ; `docs/superpowers/specs/2026-09-26-kibo-ia.md` **§14** (gabarit, skill, permissions `cap:`, faux `claude`). Sources : demande d'Adam du 2026-10-04 ; `docs/superpowers/rapports/2026-10-04-jalon-v1.3.md` ; `docs/superpowers/plans/2026-10-04-kibo-phase-12.md` (format et conventions).

## Décisions d'exécution

Les décisions de comportement sont dans les specs (composants §19, conception §19, IA §14) ; le plan ne les répète pas.

1. **Capacités = permissions** : aucune colonne ni champ nouveau hors `GrantedPermissions.capabilities` ; `permissionList` émet `cap:<nom>` ; `covers` marche tel quel (`includes`). `ValidationReport` ne change pas.
2. **`capability()` sur le SDK** : les kits appellent `sdk.capability("…")` au montage ; c'est ce qui rend l'usage visible au SDK simulé (`used`) et à l'inférence (littéral). `sdk.capabilities` (déclarées) est exposé pour l'affichage (« plein écran disponible »).
3. **Un seul envoi : par morceaux** (pas de route brute, pas de hausse de `MAX_BODY_BYTES`) ; l'interface découpe avec `File.slice`, le démon écrit en `append` dans `.uploads/<uploadId>` puis `link` exclusif. Importer depuis un chemin local (coque Tauri) : plus tard.
4. **Jetons sur le port bac à sable** pour tout le monde (intégrés compris) : une seule forme d'URL ; la CSP du document de l'interface s'élargit à l'origine du bac à sable pour `connect`, `img`, `media`.
5. **Mode plein écran = même nœud DOM** : la carte du widget reçoit `fixed inset-0 z-50` ; aucun remontage, format inchangé ; l'état du jeu survit. Rendu dans `PageView` via un `PageContext { focusedId, dispatch, bus }` unique par page (`pages/PageContext.tsx`, `usePageContext()`, `usePageState(focusable)`), qui porte aussi le bus de sélection ; une page Vue passe `focusable = []` et n'offre jamais le mode, sans refus journalisé.
6. **Capacités d'une instance côté hôte** : pour un intégré, `manifest.capabilities` ; pour un tiers, `manifest.capabilities` de la version **active** du `ComponentSummary` (égal à `granted.capabilities` : l'approbation prend `grantedOf(manifest stocké)` et l'empreinte garde le manifeste). L'hôte ne modifie pas `ComponentVersionSummary`.
7. **Kit 3D sans GPU** : `ThreeCanvas` prend `createRenderer?: (canvas) => WebGLRenderer | null` ; en test, une fabrique factice compte `render`, `setSize`, `dispose`. `three` s'importe sous Bun (classes pures) : `Scene`, `Mesh`, `BufferGeometry`, `GLTFLoader.parse` fonctionnent sans DOM graphique.
8. **Gabarits = chaînes TypeScript** dans `packages/devkit/src/templates/*.ts` (pas de fichiers `.fixture` copiés : la chaîne reste typée par le test de validation qui scaffolde puis `validateComponent` chaque gabarit, 240 s).
9. **Intégrés chargés à la demande** : `components/viewer-3d/src/index.ts` et `components/snake/src/index.ts` exportent `Component = lazyPanel(() => import("./Viewer3d"), fr.lazy)` ; `three` n'est atteint que par `import()`.
10. **`SelectionChip`** dans le SDK (`packages/sdk/src/selection-chip.tsx`, exporté par l'index) : petit, partagé par Kanban et Tickets, utilisable par un composant tiers.

export function capabilityOfPermission(entry: string): Capability | null {
  if (!entry.startsWith(PREFIX)) return null;
  const parsed = Capability.safeParse(entry.slice(PREFIX.length));
  return parsed.success ? parsed.data : null;
}

type CapabilityFields = { capabilities?: readonly Capability[] | undefined };

export const capabilitiesOf = (m: CapabilityFields): Capability[] => [...(m.capabilities ?? [])];

export function capabilityIssue(m: CapabilityFields & { kind: ComponentKind }): string | null {
  const declared = m.capabilities ?? [];
  if (new Set(declared).size !== declared.length) return "INVALID_MANIFEST: capabilities must be unique";
  if (m.kind === "adapter" && declared.length > 0) return "INVALID_MANIFEST: an adapter has no capability";

}

import { type Material, Mesh, type Object3D, Texture } from "three";

const isDisposable = (v: unknown): v is { dispose(): void } =>
  typeof v === "object" && v !== null && typeof (v as { dispose?: unknown }).dispose === "function";

function texturesOf(material: Material): Texture[] {
  return Object.values(material).filter((v): v is Texture => v instanceof Texture);
}

export function disposeObject(root: Object3D): number {
  const seen = new Set<{ dispose(): void }>();
  root.traverse((node) => {
    if (!(node instanceof Mesh)) return;
    seen.add(node.geometry);
    const materials: Material[] = Array.isArray(node.material) ? node.material : [node.material];
    for (const material of materials) {
      for (const texture of texturesOf(material)) seen.add(texture);
      seen.add(material);
    }
  });

export type ThemeColors = { background: Color; foreground: Color; muted: Color };
export const ZINC_FALLBACK = {
  dark: { background: 0x18181b, foreground: 0xfafafa, muted: 0x27272a },
  light: { background: 0xffffff, foreground: 0x09090b, muted: 0xf4f4f5 },
} as const;

export function parseCssColor(css: string, probe: CanvasRenderingContext2D | null): [number, number, number] | null {
  if (!probe || css.trim() === "") return null;
  probe.fillStyle = "#000";
  probe.fillStyle = css;
  probe.fillRect(0, 0, 1, 1);
  const [r, g, b] = probe.getImageData(0, 0, 1, 1).data;
  return r === undefined || g === undefined || b === undefined ? null : [r, g, b];
}

export function probeContext(doc: Document = document): CanvasRenderingContext2D | null {
  const canvas = doc.createElement("canvas");
  canvas.width = 1;
  canvas.height = 1;
  return canvas.getContext("2d", { willReadFrequently: true });
}

const rgb = (parts: [number, number, number]) => new Color(parts[0] / 255, parts[1] / 255, parts[2] / 255);

export function themeColors(
  root: Element = document.documentElement,
  probe: CanvasRenderingContext2D | null = probeContext(),
  dark: boolean = root.classList.contains("dark"),
): ThemeColors {
  const fallback = dark ? ZINC_FALLBACK.dark : ZINC_FALLBACK.light;
  const style = getComputedStyle(root);
  const read = (name: string, backup: number) => {
    const parsed = parseCssColor(style.getPropertyValue(name), probe);
    return parsed ? rgb(parsed) : new Color(backup);
  };
  return {
    background: read("--card", fallback.background),
    foreground: read("--foreground", fallback.foreground),
    muted: read("--muted", fallback.muted),

}

import type { Selection } from "@kibo/schema";
import type { FocusApi, SelectionApi, VisibilityApi } from "./types";

export type Signal<T> = { get(): T; set(value: T): void; subscribe(listener: () => void): () => void };

export function createSignal<T>(initial: T): Signal<T> {
  let value = initial;
  const listeners = new Set<() => void>();
  return {
    get: () => value,
    set(next) {
      if (Object.is(next, value)) return;
      value = next;
      for (const l of listeners) l();
    },
    subscribe(l) {
      listeners.add(l);
      return () => {
        listeners.delete(l);
      };
    },
  };
}

export const focusApi = (active: Signal<boolean>, onRequest: (on: boolean) => void): FocusApi => ({
  active: active.get,
  request: () => onRequest(true),
  exit: () => onRequest(false),
  subscribe: active.subscribe,
});
export const visibilityApi = (visible: Signal<boolean>): VisibilityApi => ({ visible: visible.get, subscribe: visible.subscribe });
export const selectionApi = (sel: Signal<Selection | null>, onSet?: (s: Selection | null) => void): SelectionApi => ({
  get: sel.get,
  set(next) {
    sel.set(next);

import { constants, open, readdir, stat, unlink } from "node:fs/promises";
import { join } from "node:path";
import { assetKindOf, extensionMatches, KiboError, type ProjectAsset, type ProjectAssetMime, ProjectAssetName, sniffAsset } from "@kibo/schema";
import { resolveInside } from "../fs/resolve-inside";

const HEAD = 16;
const notFound = (name: string) => new KiboError("NOT_FOUND", `project file ${name} not found`);
const isMissing = (e: unknown) => typeof e === "object" && e !== null && (e as { code?: string }).code === "ENOENT";

async function sniffHead(path: string): Promise<{ mime: ProjectAssetMime | null; size: number } | null> {
  let file: Awaited<ReturnType<typeof open>> | null = null;
  try {
    file = await open(path, constants.O_RDONLY | constants.O_NOFOLLOW);
    const info = await file.stat();
    if (!info.isFile()) return null;
    const head = new Uint8Array(HEAD);
    const { bytesRead } = await file.read(head, 0, HEAD, 0);
    return { mime: sniffAsset(head.subarray(0, bytesRead)), size: info.size };
  } catch (e) {
    if (isMissing(e)) return null;
    throw e;
  } finally {
    await file?.close();
  }
}

export async function describeAssetFile(dir: string, name: string): Promise<ProjectAsset | null> {
  if (!ProjectAssetName.safeParse(name).success) return null;
  const full = await resolveInside(dir, name, "project file");
  const head = await sniffHead(full);
  if (!head || head.mime === null || !extensionMatches(name, head.mime)) return null;
  const info = await stat(full);
  return { name, mime: head.mime, kind: assetKindOf(head.mime), size: head.size, mtime: info.mtimeMs };
}

export async function listAssetFiles(dir: string): Promise<ProjectAsset[]> {
  let names: string[];
  try {
    names = await readdir(dir);
  } catch (e) {
    if (isMissing(e)) return [];

export const FIXED_STEP = 1 / 60;
export function stepAccumulator(acc: number, dt: number, fixed = FIXED_STEP, maxSteps = 5): { steps: number; rest: number } {
  const total = acc + dt;
  const steps = Math.min(maxSteps, Math.floor(total / fixed));
  return { steps, rest: steps === maxSteps ? 0 : total - steps * fixed };
}

export type KeyState = ReadonlySet<string>;
export type KeyEvent = { type: "keydown" | "keyup" | "blur"; code: string };
export const GAME_KEYS: readonly string[] = ["ArrowUp", "ArrowDown", "ArrowLeft", "ArrowRight", "Space"];
export function keysReducer(state: KeyState, e: KeyEvent): KeyState {
  if (e.type === "blur") return new Set();
  const next = new Set(state);
  if (e.type === "keydown") next.add(e.code);
  else next.delete(e.code);

  if (!pad) return NO_PAD;

    axes: pad.axes.map((a) => (Math.abs(a) < deadzone ? 0 : a)),

export function createStage(scene: Scene, camera: PerspectiveCamera) {
  scene.add(new AmbientLight(0xffffff, 0.9), new DirectionalLight(0xffffff, 1.1));
  let current: Object3D | null = null;
  return {
    show(model: Object3D) {
      if (current) { scene.remove(current); disposeObject(current); }
      current = model;
      scene.add(model);
      fitCameraTo(model, camera);
    },
    turn(dt: number) { if (current) current.rotation.y += dt * ROTATION_SPEED; },
    clear() { if (current) { scene.remove(current); disposeObject(current); current = null; } },
  };
}

export type Dir = "up" | "down" | "left" | "right";
export type Cell = { x: number; y: number };
export type Game = { w: number; h: number; snake: Cell[]; dir: Dir; next: Dir; apple: Cell; score: number; alive: boolean };
const OPPOSITE: Record<Dir, Dir> = { up: "down", down: "up", left: "right", right: "left" };
const DELTA: Record<Dir, Cell> = { up: { x: 0, y: -1 }, down: { x: 0, y: 1 }, left: { x: -1, y: 0 }, right: { x: 1, y: 0 } };
export function spawnApple(w: number, h: number, snake: readonly Cell[], rng: () => number): Cell {
  const free: Cell[] = [];
  for (let y = 0; y < h; y++) for (let x = 0; x < w; x++) if (!snake.some((c) => c.x === x && c.y === y)) free.push({ x, y });
  return free[Math.min(free.length - 1, Math.floor(rng() * free.length))] ?? { x: 0, y: 0 };
}
export function newGame(w: number, h: number, rng: () => number): Game {
  const head = { x: Math.floor(w / 2), y: Math.floor(h / 2) };
  const snake = [head, { x: head.x - 1, y: head.y }, { x: head.x - 2, y: head.y }];
  return { w, h, snake, dir: "right", next: "right", apple: spawnApple(w, h, snake, rng), score: 0, alive: true };
}
export const turn = (g: Game, dir: Dir): Game => (dir === OPPOSITE[g.dir] ? g : { ...g, next: dir });
export function step(g: Game, rng: () => number): Game {
  if (!g.alive) return g;
  const dir = g.next;
  const head = g.snake[0];
  if (!head) return { ...g, alive: false };
  const to = { x: head.x + DELTA[dir].x, y: head.y + DELTA[dir].y };
  const eats = to.x === g.apple.x && to.y === g.apple.y;
  const body = eats ? g.snake : g.snake.slice(0, -1);
  const hit = to.x < 0 || to.y < 0 || to.x >= g.w || to.y >= g.h || body.some((c) => c.x === to.x && c.y === to.y);
  if (hit) return { ...g, dir, alive: false };
  const snake = [to, ...body];
  return { ...g, dir, snake, score: g.score + (eats ? 1 : 0), apple: eats ? spawnApple(g.w, g.h, snake, rng) : g.apple, alive: true };
}

export const chunksOf = (size: number): { index: number; start: number; end: number }[] =>
  Array.from({ length: Math.ceil(size / UPLOAD_CHUNK_BYTES) }, (_, index) => ({
    index, start: index * UPLOAD_CHUNK_BYTES, end: Math.min(size, (index + 1) * UPLOAD_CHUNK_BYTES),
  }));
export async function uploadFile(rpc: Pick<KiboClient, "rpc">, projectId: string, name: string, mime: ProjectAssetMime, file: Blob, onProgress: (ratio: number) => void = () => {}): Promise<ProjectAsset> {
  const { uploadId } = await rpc.rpc({ method: "beginAssetUpload", projectId, name, mime, size: file.size });
  try {
    for (const chunk of chunksOf(file.size)) {
      const bytes = new Uint8Array(await file.slice(chunk.start, chunk.end).arrayBuffer());
      const { received } = await rpc.rpc({ method: "appendAssetUpload", uploadId, index: chunk.index, bytes: bytesToBase64(bytes) });
      onProgress(received / file.size);
    }
    return await rpc.rpc({ method: "finishAssetUpload", uploadId });
  } catch (e) {
    await rpc.rpc({ method: "cancelAssetUpload", uploadId }).catch((c: unknown) => console.error("[kibo-ui] upload not cancelled", c));
    throw e;
  }
}
// files/slug.ts
export function slugName(original: string): string | null {
  const dot = original.lastIndexOf(".");
  if (dot <= 0) return null;
  const ext = original.slice(dot + 1).toLowerCase();
  const base = original.slice(0, dot).normalize("NFD").replace(/[̀-ͯ]/g, "").toLowerCase().replace(/[^a-z0-9._-]+/g, "-").replace(/^[^a-z0-9]+|-+$/g, "");
  const name = `${base || "fichier"}.${ext}`;
  return ProjectAssetName.safeParse(name).success ? name : null;
}
