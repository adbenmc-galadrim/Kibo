# Kibo · Phase 15 : cadres Figma et Penpot dans les composants Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** livrer la section « Ensuite · Intégrations » de la feuille de route : un composant affiche un **cadre Figma ou un board Penpot** rendu par le démon (jamais par le composant), avec le **jeton dans le trousseau système** (Figma : jeton personnel, API REST, en plus du serveur MCP local de la phase 5 ; Penpot : jeton d'accès d'une instance penpot.app ou auto-hébergée), un **cache local hors CRDT** invalidé par la version du cadre et servi **hors ligne** avec l'état « périmé », les liens cadre ⇄ ticket étendus à Penpot, un intégré **« Maquette »** écrit avec le SDK public, l'écran 16 et ses dialogues de connexion. Aucun secret réel, aucun réseau : faux Figma et faux Penpot locaux.

**Architecture:** le démon gagne un module `design/` au-dessus du socle d'intégrations de la phase 5 : deux fournisseurs (`figma-rest`, `figma-mcp` repris de D1, `penpot`), deux comptes (jeton dans `SecretStore`, réglages dans `integration_settings`), un **service de cadres** (politique frais / revalidation par version / repli périmé) sur un **cache SQLite + fichiers** (`design_cache`, `<KIBO_HOME>/cache/design/`), et des images servies par le **port bac à sable** sous `GET /d/<jeton>/frame.<ext>` (jetons éphémères des fichiers de projet, généralisés). Le composant n'a que `sdk.design.frame(url)` sous la **capacité `design`** ; le réseau des intégrations gagne un en-tête d'authentification paramétrable (`X-Figma-Token`, `Authorization: Token`) et `http:` en boucle locale pour une instance Penpot locale. L'interface ajoute la ligne Penpot, un dialogue Figma à deux modes, un dialogue Penpot, la section « Maquettes » à deux fournisseurs, un champ URL de cadre dans les réglages, et le widget Maquette, tout en différé.

**Tech Stack:** Bun 1.4.2, TypeScript 5.9 strict, Zod 3.25.76, React 19, shadcn/ui, happy-dom + Testing Library, fast-check, Playwright ; `@modelcontextprotocol/sdk` (déjà présent, D1). **Aucune dépendance nouvelle.**

**Spec:** `docs/superpowers/specs/2026-09-25-kibo-design.md` **§21** (écrite pour ce plan : 21.1 clé et URL, 21.2 rendu et capacité, 21.3 cache, 21.4 comptes et réseau, 21.5 fournisseurs, 21.6 composant Maquette, 21.7 écran 16, 21.8 textes et budget, 21.9 tests, 21.10 Adam, 21.11 codes) ; spec F `2026-09-26-kibo-integrations.md` **§15** (amendements §3.1, §3.3, §3.4, §8.2, §9, §10, §11) ; spec composants §19 point 13 ; spec F §8.2 et N13, N21 (D1 conservé). Sources : feuille de route « Ensuite · Intégrations » ; `docs/superpowers/rapports/2026-10-04-jalon-v1.5.md` ; `docs/superpowers/plans/2026-10-04-kibo-phase-14.md` (format).

## Global Constraints

- Bun **1.4.2**, dépendances figées par `bun.lock`, aucun `postinstall`, **aucune dépendance nouvelle**.
- **Aucun secret, aucun compte** : les tests et l'E2E n'utilisent que les faux serveurs (`127.0.0.1`), `--test-origins` et `--memory-secrets` (N9, N42) ; un jeton réel n'apparaît que dans le contrôle manuel du jalon, sur la machine d'Adam.
- **Un composant ne touche jamais le réseau** : `net` ne change pas, aucune capacité réseau (décision d'Adam en attente, spec composants §19) ; l'image vient du démon par le port bac à sable (§21.2).
- **Secrets** : trousseau système uniquement (`SecretStore`, `Bun.secrets`) ; jamais dans le CRDT, SQLite, les journaux, les messages d'erreur, `brief.md`, l'environnement d'un agent ; `redactor.add` à chaque lecture ; le test de fuite (`integrations/leak.test.ts`) est étendu aux jetons Figma et Penpot factices.
- **Réseau des intégrations** : `createIntegrationFetch` uniquement (anti-SSRF, épinglage, redirections ≤ 3, corps borné, N44) ; `http:` seulement en boucle locale et seulement pour l'hôte d'une instance Penpot configurée ; aucun autre assouplissement. **Relecture du lead obligatoire : T1, T3, T5, T6.**
- **Aucun commentaire dans le code** ; code, identifiants, messages d'erreur internes en anglais ; textes d'interface en français, tutoiement, dans `packages/ui/src/i18n/fr-design.ts` chargé à la demande (§21.8).
- **Budget de 230 kB jamais relevé.** Mesure de départ **223,5 kB** (jalon v1.5). **Exigence de la phase : ≤ 224,5 kB** (gzip, entrée ; spec §21.8). ## Décisions d'exécution

Les décisions de comportement sont dans la spec (§21) ; le plan ne les répète pas.

1. **`figma/` disparaît** : `parseFigmaUrl` part dans `schema/src/design.ts` (sous `parseDesignUrl`), `nameFromMetadata` dans `design/providers/figma-mcp.ts`, le reste de `figma.ts` est réparti entre `figma-account.ts` (configure MCP, status, test, disconnect) et `providers/figma-mcp.ts` (`get_metadata`, `get_screenshot`). Les tests `figma.test.ts` sont réécrits au même endroit que le code qu'ils couvrent. `figma_cache` et `cache/figma` sont supprimés à la migration (T4).
2. **Un seul service de cadres** pour les widgets et la fiche ticket : `getDesignFrame` (shell) et `design.frame` (composants) appellent `FrameService.frame(instanceId, url, refresh)` ; le shell frappe ses jetons sous `instanceId = "shell"` avec `DESIGN_TOKENS_SHELL = 256`.
3. **Jetons génériques** : `files/tokens.ts` devient un cas de `components/grant-tokens.ts` (`createGrantTokens<G>`), sans changer `FileGrant` ni les tests des fichiers de projet.
4. **Fournisseur = interface pure** `DesignProviderClient { id, connected(), version(key), metadata(key), render(key) }` ; le service ne connaît ni HTTP ni MCP ; chaque fournisseur est testé contre son faux serveur, le service contre des fournisseurs simulés.
5. **Pause de débit** : par fournisseur, en mémoire (`pausedUntil`), posée par un `429` (`retry-after`, 60 s au moins) ; pendant la pause toute requête est refusée par `RATE_LIMITED` sans réseau (le service sert alors le cache périmé).
6. **Hôte du démon** : `IntegrationHost` gagne `sandboxOrigin(): string \| null` (le port bac à sable démarre après les intégrations : la fonction lit une variable posée plus tard, comme `createComponentsService`).
7. **RPC nouvelles = handlers du module d'intégration** (`IntegrationHandlers`), pas d'extension RPC : `connectFigma`, `connectPenpot`, `linkDesignFrame`, `getDesignFrame` sont déclarées dans `INTEGRATION_RPC` et routées par `createIntegrationRpc` comme en phase 5. Les trois méthodes retirées (`configureFigma`, `linkFigmaNode`, `getFigmaPreview`) n'ont qu'un appelant chacune dans l'interface.
8. **Textes** : `fr-design.ts` (différé) regroupe `connect` (dialogues Figma et Penpot), `sheet` (section Maquettes), `field` (champ de cadre des réglages) ; T8 le crée et y déménage d'un coup les textes Figma de `fr-integrations.ts` (bloc `figma`, `sheet.figma*`, `errors.figma*`) ; T9 et T10 n'y ajoutent rien (le composant a son `fr.ts`).
9. **Icônes** : Lucide 1.x n'a pas d'icône de marque (N15) : `Frame` pour Figma (inchangé), `PenTool` pour Penpot, `Frame` aussi pour le composant Maquette.

import { z } from "zod";
import type { ExternalRef } from "./external-ref";
import { mcpUrlAllowed, WebUrl } from "./integrations";

export const DESIGN_PROVIDERS = ["figma", "penpot"] as const;
export const DesignProvider = z.enum(DESIGN_PROVIDERS);
export type DesignProvider = z.infer<typeof DesignProvider>;
export const Uuid = z.string().regex(/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i);
export const PenpotInstanceUrl = z.string().url().refine(mcpUrlAllowed, "https required unless loopback");
export const FigmaFrameKey = z.object({
  provider: z.literal("figma"),
  fileKey: z.string().regex(/^[A-Za-z0-9]{6,64}$/),
  nodeId: z.string().regex(/^\d+:\d+$/),
});
export const PenpotFrameKey = z.object({
  provider: z.literal("penpot"),
  instance: PenpotInstanceUrl,
  fileId: Uuid,
  pageId: Uuid,
  boardId: Uuid,
});
export const DesignFrameKey = z.discriminatedUnion("provider", [FigmaFrameKey, PenpotFrameKey]);
export type DesignFrameKey = z.infer<typeof DesignFrameKey>;
export type ParsedDesignUrl = { key: DesignFrameKey; url: string };

export const DESIGN_URL_MAX = 2048;
export const DESIGN_FRESH_MS = 3_600_000;
export const MAX_FRAME_BYTES = 4 * 1024 * 1024;
export const MAX_DESIGN_CACHE_BYTES = 200 * 1024 * 1024;
export const DESIGN_CACHE_IDLE_MS = 90 * 86_400_000;
export const DESIGN_TOKENS_SHELL = 256;
export const FrameMime = z.enum(["image/png", "image/webp", "image/jpeg"]);
export type FrameMime = z.infer<typeof FrameMime>;
const EXTENSIONS: Record<FrameMime, "png" | "webp" | "jpg"> = { "image/png": "png", "image/webp": "webp", "image/jpeg": "jpg" };
export const frameExtension = (mime: FrameMime): "png" | "webp" | "jpg" => EXTENSIONS[mime];

export const DesignFrame = z.object({
  id: z.string().min(1),
  provider: DesignProvider,
  name: z.string(),
  width: z.number().nullable(),
  height: z.number().nullable(),
  url: z.string().url(),
  mime: FrameMime,
  fetchedAt: z.number(),
  stale: z.boolean(),
  reachable: z.boolean(),
  source: WebUrl,
});
export type DesignFrame = z.infer<typeof DesignFrame>;

export const PenpotBoardRef = z.object({
  kind: z.literal("penpot_board"),
  instance: PenpotInstanceUrl,
  fileId: Uuid,
  pageId: Uuid,
  boardId: Uuid,
  url: WebUrl,
  name: z.string().max(200),
});
export type PenpotBoardRef = z.infer<typeof PenpotBoardRef>;

const FIGMA_HOSTS = new Set(["figma.com", "www.figma.com"]);
const FIGMA_PATH = /^\/(?:design|file|proto)\/([A-Za-z0-9]{6,64})(?:\/|$)/;
const FIGMA_NODE = /^(\d+)[-:](\d+)$/;
const PENPOT_WORKSPACE = /^\/workspace\/[^/]+\/[^/]+\/([^/?]+)$/;
const PENPOT_VIEW = /^\/view\/([^/?]+)$/;

function figmaKey(u: URL): DesignFrameKey | null {
  if (u.protocol !== "https:" || !FIGMA_HOSTS.has(u.hostname)) return null;
  const file = FIGMA_PATH.exec(u.pathname);
  const node = FIGMA_NODE.exec(u.searchParams.get("node-id") ?? "");
  if (!file?.[1] || !node) return null;
  return { provider: "figma", fileKey: file[1], nodeId: `${node[1]}:${node[2]}` };
}

function penpotKey(u: URL): DesignFrameKey | null {
  if (!mcpUrlAllowed(u.origin)) return null;
  const hash = u.hash.startsWith("#") ? u.hash.slice(1) : u.hash;
  const [path = "", query = ""] = hash.split("?");
  const params = new URLSearchParams(query);
  const fileId = PENPOT_WORKSPACE.exec(path)?.[1] ?? PENPOT_VIEW.exec(path)?.[1] ?? params.get("file-id");
  const candidate = { provider: "penpot" as const, instance: u.origin, fileId, pageId: params.get("page-id"), boardId: params.get("board-id") };
  const parsed = PenpotFrameKey.safeParse(candidate);
  return parsed.success ? parsed.data : null;
}

export function parseDesignUrl(raw: string): ParsedDesignUrl | null {
  const text = raw.trim();
  if (text.length === 0 || text.length > DESIGN_URL_MAX || !URL.canParse(text)) return null;
  const u = new URL(text);
  if (u.username !== "" || u.password !== "") return null;
  const key = figmaKey(u) ?? penpotKey(u);
  return key ? { key, url: u.toString() } : null;
}

export function designFrameId(key: DesignFrameKey): string {
  if (key.provider === "figma") return `figma:${key.fileKey}/${key.nodeId}`;
  return `penpot:${new URL(key.instance).host}/${key.fileId}/${key.pageId}/${key.boardId}`;
}

export function frameKeyOfRef(ref: ExternalRef): DesignFrameKey | null {
  if (ref.kind === "figma_node") return { provider: "figma", fileKey: ref.fileKey, nodeId: ref.nodeId };
  if (ref.kind === "penpot_board") {
    return { provider: "penpot", instance: ref.instance, fileId: ref.fileId, pageId: ref.pageId, boardId: ref.boardId };
  }
  return null;
}

  );

  const total = db.query<{ n: number | null }, []>("SELECT sum(bytes) AS n FROM design_cache");
  const oldest = db.query<Row, []>("SELECT * FROM design_cache ORDER BY used_at ASC LIMIT 1");
  const idle = db.query<Row, { before: number }>("SELECT * FROM design_cache WHERE used_at < $before");

    del.run({ id: row.frame_id });
    rmSync(row.path, { force: true });
  };
  const totalBytes = () => total.get()?.n ?? 0;
  const evict = () => {
    while (totalBytes() > maxTotal) {
      const row = oldest.get();
      if (!row) return;
      remove(row);
    }
  };
  return {
    get(id) {
      const row = select.get({ id });
      if (!row) return null;
      if (!existsSync(row.path)) {
        del.run({ id });
        return null;
      }
      db.query("UPDATE design_cache SET used_at = $now WHERE frame_id = $id").run({ now: deps.now(), id });
      return rowToFrame(row);
    },
    put(input) {
      if (input.body.byteLength > maxBytes) throw new KiboError("TOO_LARGE", `frame image exceeds ${maxBytes} bytes`);
      if (sniffImage(input.body) !== input.mime) throw new KiboError("INVALID_INPUT", "frame image does not match its mime");

      mkdirSync(dir, { recursive: true, mode: 0o700 });
      writeFileSync(path, input.body, { mode: 0o600 });

      immediateTransaction(db, () => {
        upsert.run(row);
        evict();
      })();
      return rowToFrame(row);
    },
    touch(id, fetchedAt) {
      const now = deps.now();
      if (fetchedAt === null) db.query("UPDATE design_cache SET used_at = $now WHERE frame_id = $id").run({ now, id });
      else db.query("UPDATE design_cache SET used_at = $now, fetched_at = $at WHERE frame_id = $id").run({ now, at: fetchedAt, id });
    },
    remove(id) {
      const row = select.get({ id });
      if (row) remove(row);
    },
    purge() {
      const rows = idle.all({ before: deps.now() - idleMs });
      for (const row of rows) remove(row);
      return rows.length;
    },
    totalBytes,
  };
}

export type RatePause = { active(): boolean; until(): number | null; set(retryAfterSeconds: number | null): void };
export function createRatePause(now: () => number, minMs = 60_000): RatePause {
  let until: number | null = null;
  return {
    active: () => until !== null && now() < until,
    until: () => until,
    set(retryAfterSeconds) {
      const wait = Math.max(minMs, (retryAfterSeconds ?? 0) * 1000);
      const next = now() + wait;
      until = until === null ? next : Math.max(until, next);
    },
  };
}

import {
  ASSET_URL_TTL_MS,
  DESIGN_FRESH_MS,
  DESIGN_TOKENS_SHELL,
  type DesignFrame,
  type DesignFrameKey,
  type DesignProvider,
  designFrameId,
  frameExtension,
  KiboError,
  parseDesignUrl,
} from "@kibo/schema";
import type { ServedFile } from "../components/file-response";
import { createGrantTokens } from "../components/grant-tokens";
import type { EventLog } from "../integrations/events";
import type { CachedFrame, FrameCache } from "./frame-cache";
import { type DesignProviderClient, type FrameMeta, UNREACHABLE_CODES } from "./providers/types";

export type FrameService = {
  frame(instanceId: string, url: string, refresh: boolean): Promise<DesignFrame>;
  metadata(key: DesignFrameKey): Promise<FrameMeta>;
  open(token: string): Promise<ServedFile | null>;
};
type Deps = { cache: FrameCache; providers: Record<DesignProvider, DesignProviderClient>; sandboxOrigin(): string | null; now(): number; events: EventLog; freshMs?: number };
type Grant = { path: string; mime: CachedFrame["mime"]; size: number };
const SHELL = "shell";
const unreachable = (e: unknown) => e instanceof KiboError && UNREACHABLE_CODES.has(e.code);

export function createFrameService(deps: Deps): FrameService {
  const fresh = deps.freshMs ?? DESIGN_FRESH_MS;
  const widgetTokens = createGrantTokens<Grant>({ now: deps.now, ttlMs: ASSET_URL_TTL_MS });
  const shellTokens = createGrantTokens<Grant>({ now: deps.now, ttlMs: ASSET_URL_TTL_MS, perInstance: DESIGN_TOKENS_SHELL });
  const parse = (raw: string) => {
    const parsed = parseDesignUrl(raw);
    if (!parsed) throw new KiboError("INVALID_INPUT", "not a figma or penpot frame url");
    return parsed;
  };
  const view = (instanceId: string, hit: CachedFrame, source: string, stale: boolean, reachable: boolean): DesignFrame => {
    const origin = deps.sandboxOrigin();
    if (!origin) throw new KiboError("INTERNAL", "sandbox listener not started");
    const tokens = instanceId === SHELL ? shellTokens : widgetTokens;
    const { token } = tokens.mint(instanceId, { path: hit.path, mime: hit.mime, size: hit.bytes });
    return { id: hit.id, provider: hit.provider, name: hit.name, width: hit.width, height: hit.height, url: `${origin}/d/${token}/frame.${frameExtension(hit.mime)}`, mime: hit.mime, fetchedAt: hit.fetchedAt, stale, reachable, source };
  };
  const renderInto = async (provider: DesignProviderClient, key: DesignFrameKey, id: string): Promise<CachedFrame> => {
    const r = await provider.render(key);
    return deps.cache.put({ id, provider: key.provider, name: r.meta.name, width: r.meta.width, height: r.meta.height, mime: r.mime, version: r.version, fetchedAt: deps.now(), body: r.body });
  };
  const revalidate = async (provider: DesignProviderClient, key: DesignFrameKey, id: string, hit: CachedFrame | null): Promise<CachedFrame> => {
    if (hit) {
      const version = await provider.version(key);
      if (version !== null && version === hit.version) {
        deps.cache.touch(id, deps.now());
        return { ...hit, fetchedAt: deps.now() };
      }
    }
    return renderInto(provider, key, id);
  };
  return {
    async frame(instanceId, raw, refresh) {
      const { key, url } = parse(raw);
      const id = designFrameId(key);
      const hit = deps.cache.get(id);
      if (hit && !refresh && deps.now() - hit.fetchedAt < fresh) return view(instanceId, hit, url, false, true);
      const provider = deps.providers[key.provider];
      if (!(await provider.connected())) {
        if (hit) return view(instanceId, hit, url, true, false);
        throw new KiboError("NOT_CONNECTED", `${key.provider} is not connected`);
      }
      try {
        return view(instanceId, await revalidate(provider, key, id, hit), url, false, true);
      } catch (e) {
        if (!unreachable(e) || !hit) throw e;
        deps.events.log(key.provider, "warn", `frame ${id} served stale: ${e instanceof KiboError ? e.detail : String(e)}`);
        return view(instanceId, hit, url, true, false);
      }
    },
    metadata: (key) => deps.providers[key.provider].metadata(key),
    async open(token) {
      const grant = widgetTokens.lookup(token) ?? shellTokens.lookup(token);
      return grant ? { path: grant.path, name: `frame.${frameExtension(grant.mime)}`, mime: grant.mime, size: grant.size } : null;
    },
  };
}

export function mockDesignFrame(frames: readonly MockFrame[], url: string, refresh: boolean, now = Date.now()): DesignFrame {
