# Kibo · Phase 19 : Jeux itch.io et Storybook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** deux fonctions demandées par Adam le 2026-10-06, portées par **un seul mécanisme** : la **page relais** `GET /e/<jeton>` du port bac à sable, sans script, dont la CSP `frame-src` ne contient que l'origine vérifiée par le démon. (1) Un composant intégré **« Jeu itch.io »** (`components/itch`, capacité `embed` + déclaration `embeds: ["itch.io"]`) affiche l'embed HTML5 d'un jeu à partir de son code d'intégration, avec vérification d'intégrabilité par en-têtes, « Ce jeu a besoin d'Internet. » hors ligne, plein écran par le mode focus. (2) Le composant **Maquette** affiche une **story Storybook** (fournisseur `storybook` de `DesignFrameKey`, rendu par iframe, sans cache, « Storybook injoignable ») à côté des cadres Figma et Penpot, propose les **origines Storybook des worktrees** du projet (port lu dans `.env`) et **compare** la story à une maquette (côte à côte ou superposition : opacité, curseur, mêmes dimensions).

**Architecture:** `schema` (capacité `embed`, `embeds`, `EmbedKind` et attributs, `EmbedView`, fournisseur `storybook`, `FrameMime` HTML, `StorybookSettings`, `parseEnvPort`, appels `embed.open` et `design.storybooks`, code `EMBED_REFUSED`) → `sdk` (`sdk.embed.open`, `sdk.design.storybooks`, `EmbedFrame`, simulations) → `daemon` (`embed/` : relais, vérification d'intégrabilité, jetons, porte ; `design/` : client Storybook, origines du projet et des worktrees, règle d'origine, branche HTML sans cache de `frame-service` ; réglage local `storybook` du projet ; CSP `frame-src 'self'` des composants sandboxés) → `components/itch` et `components/mockup` (SDK public seulement) → `ui` (section « Storybook » du dialogue « Modifier le projet », compensation du budget) → E2E contre un faux itch.io et un faux Storybook, Penpot, jalon.

**Tech Stack:** TypeScript strict, Zod, Bun (`Bun.serve`, SQLite inchangé), React 19 + shadcn/ui, fast-check, Playwright ; **aucune dépendance nouvelle**.

**Spec:** conception **§25** (autorité ; amende §6, §8, §11, §19, §21.1, §21.2, §21.6, §22.9, §23.4), composants §4.2 et §19, intégrations §10 ; CLAUDE.md. Adam a délégué toutes les décisions (2026-10-09) : rien n'est en attente de lui ; les choix que §25 laissait au plan sont dans « Décisions d'exécution ».

## Global Constraints

- **Le composant ne choisit ni l'origine ni les attributs de l'iframe** : origine vérifiée par le démon (manifeste `embeds` ou réglage `storybook` du projet), `sandbox`/`allow` fixés par `EMBED_ATTRIBUTES[kind]` (schéma) et posés par le démon (relais) et le SDK (`EmbedFrame`). La CSP du document de l'interface **ne change pas** ; celle d'un composant sandboxé gagne `frame-src 'self'` seulement avec `design` ou `embed`.
- **Zéro secret, zéro jeton de compte, zéro token d'agent** ; rien dans le CRDT (le réglage `storybook` est local comme `worktree`) ; requêtes sortantes du démon toujours par `createIntegrationFetch`, **sans `auth`**, redirections bornées au même hôte, `http:` seulement en boucle locale.
- **Dogfooding** : `components/itch` et `components/mockup` n'utilisent que `@kibo/schema` et `@kibo/sdk` ; aucun accès réseau, aucune iframe vers une URL externe directe.
- **Tests sans réseau ni token** : faux itch.io et faux Storybook sur `127.0.0.1` ; alias `--test-origins` pour que **la cible de l'iframe du relais** pointe sur le faux en E2E ; propriétés fast-check sur les analyseurs et le réducteur de comparaison.
- **Budget UI** : entrée ≤ **226,4 kB** gzip (mesure 226,3 ; plafond 230 jamais relevé) ; **T1 compense d'abord** (textes marketplace, sécurité, collab sortis de l'entrée, cible ≤ 224,5 kB), puis chaque tâche UI vérifie `bun run budget`.
- **Fichiers** : kebab-case, exports nommés, aucun commentaire, < 300 lignes (découper `FrameViewer.tsx` en `FrameSurface.tsx` + `CompareBar.tsx`), textes UI dans les `fr*.ts` des composants ou `packages/ui/src/i18n/fr-project.ts` (différé) ; une seule entrée dans l'entrée : le libellé de la capacité `embed` (`fr-trust-capabilities.ts`).
- Git : branche `feat/p19-t<n>` depuis `phase/19` (créée depuis `phase/18` + spec `42538f4f` + ce plan), worktree `.claude/worktrees/p19-t<n>` ; commits d'une ligne en français, préfixe conventionnel, **< 50 caractères**, fichiers stagés explicitement, aucune mention d'IA. `bun run check && bun run typecheck && bun test packages components` verts avant chaque commit final ; `bun run budget` pour T1, T4, T5, T6, T7.

## Décisions d'exécution

1. **Un service de relais, deux portes** : `createEmbedService` (jetons + HTML + en-têtes) ne connaît ni manifeste ni projet. `EmbedGate.open` (porte `embed.open`, sorte `game`) vérifie `embedTargetProblem(url, manifest.embeds)` puis la vérification d'intégrabilité ; `FrameService.frame` (sorte `storybook`) vérifie l'origine du projet puis sonde, et appelle `embed.open(instanceId, "storybook", url, name)`. Le relais applique `transportUrl(target, aliases)` à la cible de l'iframe (alias `--test-origins`, vide hors test) : la CSP `frame-src` cite l'origine **après** alias.
2. **Vérification d'intégrabilité générique** : `embedCheckOf(status, headers, uiOrigins)` est une table pure ; `createEmbedChecker` l'applique au résultat de `fetch(target, { method: "GET", timeoutMs: 5000, maxBytes: 65536 }, [{ host, suffix: false, auth: false }])` avec cache (`Map`, 256 entrées, 1 h ok / 60 s erreur). `uiOrigins` = `http://127.0.0.1:<uiPort>` et `http://localhost:<uiPort>` (une `frame-ancestors` qui les cite explicitement passe).
3. **`FrameMime` et images** : `ImageFrameMime` (3 valeurs) reste le type du cache et de `frameExtension` ; `FrameMime = ImageFrameMime | "text/html"` est le type de `DesignFrame.mime`. `CachedFrame.mime: ImageFrameMime` ; `view()` ne change pas pour les images.
4. **`providers: Record<DesignProvider, DesignProviderClient>`** : pour ne pas forcer un faux `DesignProviderClient` Storybook (ni `render` ni `version` n'ont de sens), `FrameServiceDeps.providers` devient `Record<ImageDesignProvider, DesignProviderClient>` (`ImageDesignProvider = "figma" | "penpot"`, schéma) et `frame()` branche sur `key.provider === "storybook"` **avant** toute lecture du cache, vers `deps.storybook: { client: StorybookClient; origins: StorybookOrigins; embed: Pick<EmbedService, "open"> }`. `metadata(key)` d'une story ⇒ `{ name, width: null, height: null }` par l'index.
5. **Hôte des intégrations** : `IntegrationHost` gagne `projectSettings: Pick<ProjectSettings, "get">` et `worktrees(folder: string): Promise<Worktree[]>` (`openRepo(folder).then((r) => r.worktrees())`, `NOT_A_REPO` ⇒ `[]`) et `uiOrigins(): string[]` ; `createIntegrationHost` les implémente (T1, contrat), T3 les consomme. `host.projects()` donne déjà `folder`.
6. **Stub T1 pour `DesignGate.storybooks`** : T1 ajoute la méthode au type et une implémentation qui lève `INTERNAL("storybook origins not wired")` dans `design/gate.ts`, pour que T2 (routage dans `components/gate.ts` et `gate-handlers.ts`) et T3 (implémentation) compilent indépendamment. T3 la remplace.
7. **`.env` : lecture bornée** : `readEnvFile(dir)` lit `.env.local` puis `.env` (`readFileSync`, 64 kio au plus, fichiers plus gros ignorés), `parseEnvPort(text, name)` (schéma, pur) rend le premier port valide ; rien d'autre n'est lu ni exécuté. Les origines sont calculées **à chaque appel** `design.storybooks` (git `worktree list` est rapide) et la sonde de chaque origine court en parallèle (`Promise.all`), résultat de sonde en cache 30 s par origine (même cache que l'index).
8. **Origine éphémère dans Maquette** : le choix du menu « Storybook : … » vit dans l'état du composant (`originOverride: string | null`, réinitialisé au changement de cadre) ; l'URL affichée est `storyUrlWithOrigin(url, override) ?? url`. Rien n'est écrit en configuration : le worktree est passager, la configuration garde l'URL saisie.
