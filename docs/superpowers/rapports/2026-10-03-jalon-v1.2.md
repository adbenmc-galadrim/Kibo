## Écarts et points ouverts

- **Alerte `glib`** (Dependabot n° 1, `Cargo.lock`) : imposée par gtk 0.18 via Tauri 2, Linux seulement, `VariantStrIter` non utilisé. À rejeter par Adam (réglage de sécurité du dépôt) : `gh api -X PATCH repos/adbenmc-galadrim/Kibo/dependabot/alerts/1 -f state=dismissed -f dismissed_reason=tolerable_risk -f dismissed_comment="glib 0.18 imposé par gtk 0.18 (Tauri 2), Linux seulement, VariantStrIter non utilisé"`. Les 9 autres alertes se ferment à la fusion dans `main`.
- **Vérification manuelle de T1/T2** (deux Kibo sur le même `KIBO_HOME`) : refusée par les permissions de l'agent, non contournée. Couverte par des tests en sous-processus (réutilisation, sortie 3, port muet) ; à faire une fois à la main : lancer Kibo deux fois.
- **Fin de tour et règles** : `run_done` part à chaque fin de tour, même quand un message en attente relance aussitôt le run ; une règle « run terminé → En review » basculerait le ticket en pleine conversation. À trancher.
- Libellé « réponse reçue · reprise de la session » affiché aussi quand un simple message (pas une réponse) relance un run terminé (`QueueItem.tsx`).
- Un run interrompu par un redémarrage du démon compte le temps d'arrêt dans sa durée (aucun événement de fin avant le redémarrage).
- Test instable sous charge : « a skeleton with role=status is shown while the build runs » (`draft-preview.test.tsx`), antérieur à la phase.
