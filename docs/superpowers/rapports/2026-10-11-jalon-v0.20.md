## Vérification réelle (chef d'équipe, 2026-10-11)

Instance isolée (`KIBO_HOME` temporaire, port 4327), vrai `claude` 2.1.296, profil Sonnet en `acceptEdits`, dépôt jetable. Trois runs.

- **Premier run, dépôt sous `~/.claude`** : le CLI refuse toute écriture dans ce dossier protégé ; le fil le montre (actions en rouge, message de l'agent qui l'explique). Il a révélé un défaut : les enregistrements de métadonnées du CLI (`atis-latch`, `last-prompt`, `cost-state`) apparaissaient comme lignes brutes dans le fil. **Corrigé** (`fix(moments): métadonnées de session ignorées`), avec un test.
- **(a) Fil** : rempli pendant le run (capture « en cours »), phrases de l'agent, actions repliées et résumées en français, échec en rouge (Bash refusé en `acceptEdits`), détail au dépli ; plus aucune ligne brute après le correctif. Aucun secret croisé.
- **(b) Plan** : déclaré par l'agent à chaque run sans rappel (3 étapes, puis 1). Le rappel `additionalContext` du `PreToolUse` n'a donc pas été déclenché en réel ; il reste couvert par le test d'intégration. Les hooks de l'environnement d'Adam (extensions globales) se chargent dans les runs ; sans effet sur le fil.
- **(c) Compte rendu** : présent à la fin, avec « Fait », « Décisions », « À vérifier », « Fichiers », « Suite » ; les fichiers sont vérifiés contre le diff (« 1 fichier modifié non mentionné » sur un dépôt partagé par deux runs).
- **(d) Stop bloqué une fois** : run avec consigne contraire ; le `Stop` est bloqué, le fil affiche « Kibo a rappelé de remplir le compte rendu », l'agent remet son compte rendu au tour suivant.
- **(e) Interface** : barre (place, file, étape en cours), page dédiée avec historique des runs, fil, plan et compte rendu, sombre et clair (`screens/2026-10-11-p20-reel/`). Le reste du parcours (volet, poignée, Activité, mention, Questions, graphe, Kanban) est couvert par les E2E et les captures de T7 à T14.
- **(f) Route MCP** : le jeton réel d'un run terminé et un jeton inventé reçoivent 401.
- **(g) Sauvegarde** : la copie de `runs.db` contient la table `run_moments`.

## Risques

- Format de transcription du CLI : il évolue (trois types nouveaux constatés en réel) ; un type inconnu isolé rend une ligne brute, une série bascule en fil partiel, sans casser.
- `additionalContext` non observé en réel ; si un agent l'ignore, le rappel de fin de tour (Stop bloqué une fois) reste le filet.
- `Notification` jamais reçu en `-p`.
- Transcriptions volumineuses et croissance de `runs.db`.
- Liens implicites du graphe surprenants pour un lecteur ; `sessionStorage` et fenêtres multiples.
- Budget de l'entrée à 31 octets du plafond de la phase.
- Fichiers à découper au prochain changement : `components/service.ts` (341 lignes), `moments/trace-service.ts` (300).
