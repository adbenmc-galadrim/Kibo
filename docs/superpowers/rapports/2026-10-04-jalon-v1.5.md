## Écarts et points ouverts

- **Paliers de budget** : T8 et T11 ensemble à 223,2 kB (palier T8 223,0, palier T10 223,2) ; la phase reste sous 224,0. Le badge « Démo » est un `span` aux classes du badge secondaire plutôt que `Badge` (+0,2 kB) pour tenir 223,5.
- **`.dmg` jamais produit en local** : le script AppleScript du Finder dépasse son délai sur ce poste ; la première release en CI le confirmera.
- **Limites connues de la signature ad hoc** : l'empreinte de code change à chaque version, donc le trousseau peut redemander l'accès (« kibo-daemon veut accéder… ») après une mise à jour ; sous macOS 13+, l'élément d'ouverture de session peut afficher le nom du binaire et une notification « éléments en arrière-plan ».
- **Lancement à l'ouverture de session** : le chemin de l'application est figé à l'activation ; déplacer Kibo le casse (désactiver puis réactiver, le texte d'aide le dit). Sous Linux, un chemin avec espace casse `Exec=` (`install.sh` installe dans `~/.local/bin`).
- **Sommes SHA256** : elles protègent d'un téléchargement corrompu, pas d'une release compromise (écrit dans le guide).
- **Démo** : une démo créée avant le marqueur n'est jamais nettoyée (sans danger) ; `setNotesDir` et `setFilesDir` restent permis sur la démo (local) ; une erreur de suppression du dossier de notes après la suppression du projet remonte une erreur alors que le projet est supprimé ; l'état du faux binaire (`demo-agent/state`) accumule des transcripts sans nettoyage.
- **Relectures, remarques mineures** : `backupFailed` non gardé par la phase `backingUp` ; clé `close` inutilisée dans `fr-report` ; « Copié » peut rester affiché à la réouverture de « Signaler un problème » ; le panneau du didacticiel ne se ferme pas à Échap et ne déplace pas le focus.
- **Taille des fichiers** : `daemon.ts` à 335 lignes et `draft-lifecycle.ts` à 299 : à découper dans une prochaine PR.
- **Test instable** : `three-canvas.test.tsx` a fait échouer une gate sous forte charge (5/5 seul) ; à stabiliser dans une prochaine PR.
- **Vérifications manuelles dans la coque** (non automatisables) : installation depuis le `.dmg`, `codesign -dv` (`Signature=adhoc`, sidecars et `kibo-demo-agent` signés), lancement à l'ouverture de session, « À propos » du menu Kibo, sauvegarde manuelle, didacticiel complet, `⌘/` ; sous Linux, `install.sh` contre une release brouillon.
