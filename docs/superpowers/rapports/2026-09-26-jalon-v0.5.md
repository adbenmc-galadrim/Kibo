## Livré

- **Contrats** : références externes et liaisons dans le doc projet, `IntegrationEvent` sur le canal existant, commandes réservées (`upsertExternalRef`, `importExternalTicket`, liaisons), permissions `secret:` et `mcp:` (consentement par hôte), erreurs distantes à code stable.
- **Socle démon** : réglages locaux, trousseau système lu à la demande (`Bun.secrets`, indisponibilité signalée sans bloquer), réseau des intégrations adossé au proxy anti-SSRF de la phase 4 (secret `github` injecté seulement vers api.github.com et uploads.github.com, réponse compressée refusée quand un secret est injecté, écho de secret caviardé), quotas et journaux partagés, caviardage global des journaux.
- **GitHub** : compte par `gh` ou jeton personnel (portées vérifiées), adaptateur GitHub Issues/Projects v2 écrit avec le SDK public et exécuté dans le Worker, moteur de sync (fusion à trois, projection des statuts, création incertaine à confirmer, 409/422, limite de débit observée), GitHub Actions (runs par PR, logs tronqués à 20 Mio, notification d'échec unique).
- **MCP** : hub (stdio en environnement exact, HTTP en boucle locale sans redirection), quota par minute, résultats caviardés, Figma Dev Mode (lier un nœud, aperçu en cache), composant « Source MCP » (un ticket par élément, titre d'instance).
- **Interface** : écran 16 (Paramètres › Intégrations) et dialogues P2 à P5, source synchronisée (P6), Sheet ticket GitHub, CI, logs et Maquettes (P7 à P9), widget Source MCP (P10), Kanban et Tickets synchronisés (P11), toasts, notices d'intégration dans le shell.
- **Qualité** : test de fuite de secret sur les couches principales et secondaires, aller-retour ticket ↔ issue sur un faux GitHub, faux serveur MCP, 36 parcours Playwright en sombre et en clair.

## Risques

- **Linux non vérifié** : ni `Bun.secrets` sous Linux (Secret Service), ni le bac à sable, ni la CI.
- **Coque Tauri non compilée** : Rust absent de la machine ; `main.rs` (répertoire des intégrés) relu à la main.
- **API GitHub** : formes réelles des réponses REST et GraphQL (Projects v2) non vérifiées contre GitHub, seulement contre le faux serveur.
- **Dépendance `@modelcontextprotocol/sdk`** : surface importante, version figée.
- **TOCTOU DNS** du réseau des intégrations (atténué par la connexion à l'adresse résolue).
- **Tests intermittents sous charge** : `run.test.ts`, `jobs.test.ts`, conformité des composants (délai de rendu), avertissements `act()` restants (notes, sandbox).
- **Maquettes** : `kibo.penpot.xz` pèse 57 Mo (limite GitHub recommandée : 50 Mo) ; le backend Penpot exige un tas de 950 Mo (réglé dans `design/penpot/docker-compose.yaml`).
- **Données fictives** : les écrans P6 à P11 utilisent `#42`, KIB-31, les dépôts `adam/*` et un serveur « Sentry », absents de `design/donnees-fictives.md`.
